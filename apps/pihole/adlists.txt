# Pi-hole adlists: Firebog "ticked" lists, minus the Malicious category.
#
# Source: https://firebog.net/ (read 2026-11-12). Only the lists marked green
# with a tick were used. The Malicious category was left out on purpose: those
# feeds (URLhaus, Phishing Army, quidsup, RPiList, ...) trade false positives
# for coverage and break logins/browsing more often than they help here.
#
# This file is the source of truth. It is mounted as a ConfigMap at
# /etc/adlists/adlists.txt and pihole-updatelists syncs gravity.db from it every
# Saturday at 03:25 (adding new lists, disabling ones removed here, then running
# gravity). Only lists commented "Managed by pihole-updatelists" are managed;
# the StevenBlack list inherited from the old setup is left alone.
#
# Apply now without waiting for the cron:
#   kubectl exec -n pihole deploy/pihole -- pihole-updatelists
#
